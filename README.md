# BreakingPoint

A 2D rage-bait platformer. The goal is to reach the end of each level without rage quitting.

Play it on itch.io: https://krasen78.itch.io/dungeon-game

## Status

Finished. This was a duo school project.

## Made by

- [Merijn Snelders](https://github.com/MerijnSnelders): background, some level design, character animations and controls
- [krasen67](https://github.com/krasen67): level design, sound design, the menu and checkpoints

## Technologies

- Unity
- C#

## Features

- 2D platformer with character animations and controls
- Multiple levels
- Checkpoints
- A game menu
- Sound design
- A trailer

## How to run it

The easiest way is to play it on [itch.io](https://krasen78.itch.io/dungeon-game). The itch.io page is still listed under the old name "dungeon-game".

To open the project yourself:

1. Clone the repository: `git clone https://github.com/MerijnSnelders/BreakingPoint.git`
2. Open the project folder with Unity Hub. Unity Hub will show which editor version the project needs.
3. Open the main scene and press Play.

I did not record which Unity version we used. The exact version is stored in `ProjectSettings/ProjectVersion.txt`.

## Process

We came up with the idea together and split the work. We built the core gameplay first. Then we created one level and polished it, followed by levels 3 and 4. Last, we made a trailer and a proper menu.
